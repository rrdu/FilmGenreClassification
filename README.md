# FilmGenreClassification
- ECE 684: NLP - Final Project
- Rebecca Du, Anish Parmar, Conrad Li

## Overview
We compare the performance of Naive Bayes, LSTM, BiLSTM, and MoE models on the task of film genre classification based on plot descriptions. 

## Data
We used the [IMDB Movie Dataset from Kaggle](https://www.kaggle.com/datasets/rajugc/imdb-movies-dataset-based-on-genre).

## Code Distribution
The code for each model is self-contained in the respective branches

- [**LSTM/BiLSTM**](https://github.com/rrdu/FilmGenreClassification/tree/LSTM)
- [**MoE**](https://github.com/rrdu/FilmGenreClassification/tree/MoE)
